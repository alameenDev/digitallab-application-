# Digital Lab — المختبر الرقمي

نسخة تصميم تفاعلية لتطبيق المريض باستخدام Flutter، بالعربية والإنكليزية. هوية كحلي/تركواز، تصميم متجاوب، وضع داكن ومسارات حجز ونتائج وملفات عائلة.

**الإصدار 0.3 هو نموذج واجهات وبيانات وهمية في ذاكرة الجلسة.** لا توجد خدمات خلفية أو دفع أو OTP أو استشارات طبية متصلة. إعادة تشغيل التطبيق تصفّر التغييرات.

## التشغيل على جهازك — Windows / VS Code

حمّل المستودع من **Code → Download ZIP** وفك الضغط، أو استخدم:

```powershell
git clone https://github.com/alameenDev/digitallab-application-.git
cd digitallab-application-
code .
flutter pub get
flutter run -d chrome
```

افتح المجلد الذي يحتوي على **pubspec.yaml** مباشرة. لا تنشئ مشروعاً متداخلاً ولا تغيّر اسم مجلد lib إلى lib copy.

المستودع يحتوي على ملفات Web الجاهزة. يستخدم فحص GitHub إصدار Flutter **3.35.7** ثابتاً لإعادة إنتاج الاختبارات.

لإضافة ملفات Android وiOS محلياً:

```powershell
flutter create --project-name digital_lab_patient --platforms=android,ios .
flutter pub get
```

إذا أنشأ Flutter اختبار العداد الافتراضي test/widget_test.dart الذي يشير إلى MyApp، احذف ذلك الملف الافتراضي فقط واحتفظ باختبارات المشروع. بناء iOS يحتاج macOS وXcode؛ تشغيل Android يحتاج جهازاً أو محاكياً مُعداً.

لتركيب التصميم فوق مشروعك الحالي احتفظ بنسخة احتياطية، ثم انسخ **lib** و**pubspec.yaml** و**test** و**analysis_options.yaml** من هذا المستودع إلى جذر مشروعك. احتفظ بمجلدات المنصات الحالية. احذف اختبار العداد الافتراضي فقط إذا بقي يشير إلى MyApp.

## إضافات الإصدار 0.3

- ثلاث بانرات مرسومة داخل Flutter، قابلة للسحب والضغط، تتبدل تلقائياً كل 7 ثوانٍ مع زر إيقاف واحترام إعداد تقليل الحركة.
- أربع قصص خدمات بعارض وخطوات تنقل وروابط للشاشات المعنية.
- مركز متابعة يجمع نتائج وحجوزات الفرد، ولوحة عائلة تعرض ملخصاً مستقلاً لكل فرد.
- خطة تحضير للزيارة: قائمة إنجاز ومذكرة أسئلة منفصلة لكل فرد. نسبة الإنجاز تخص القائمة فقط وليست تقييماً صحياً.
- مقارنة باقتين أو ثلاث حسب السعر وعدد الفحوصات والمختبر ورسوم السحب.
- صفحة للسحب المنزلي تعرض التكلفة قبل الحجز وتفتح تتبع الطلبات التجريبية.
- نادي ولاء: مستويات بتقدّم محسوب، استبدال 500/1000/1500 نقطة بقسيمة، تطبيقها في الحجز مرة واحدة، وإعادة إتاحتها عند الإلغاء.

الرسومات عناصر Flutter مدمجة ولا تحتاج صوراً أو تحميل صور من خدمة خارجية. كل هذه التفاعلات محلية ومؤقتة، دون دفع أو ربط طبي فعلي.

## ما يمكنك تجربته

- الرئيسية، البحث والفلترة، الباقات، ملفات الأطباء والمختبرات، المفضلة والمشاهدة الأخيرة.
- حجز من ثلاث خطوات: الفرد، الهاتف العراقي، نوع الزيارة، اليوم والوقت، عنوان السحب المنزلي، الملاحظات، كوبون DIGITAL10، مراجعة السعر وموافقة العرض.
- حفظ تفاصيل الحجز في الجلسة، تعديل الموعد، الإلغاء، محاكاة الاكتمال، تقييم الزيارة، تسع مراحل للسحب المنزلي.
- نتائج مستقلة لكل فرد، تقرير جاهز وآخر قيد الإجراء، قيم ووحدات ومديات ومقارنة مع قراءة سابقة ومعاينة المستند.
- إضافة أفراد للعائلة وتبديل الملف، المعلومات الصحية وبطاقة الطوارئ، قوائم المستندات والتذكيرات.
- إنشاء أذونات مشاركة تجريبية محددة المدة وإلغاؤها، دون إرسال أو إنشاء روابط عامة.
- إعدادات اللغة والمظهر وحجم الخط، الإشعارات، المكافآت والاستبدال المحلي، المحفظة والعروض والإحالات.
- واجهات تسجيل الدخول والمساعد والاستشارة والصيدلية والتأمين والدعم وبطاقة المريض والدور.
- استوديو إدارة للعرض: نظرة عامة، قوائم مقدمي الخدمة والطلبات، مسودات حملات، أدوار وتقارير ومفاتيح إعدادات تجريبية.

راجع [جدول تغطية المميزات](docs/FEATURES.md) للتمييز بين التفاعل المحلي ومعاينات الربط.

## التحقق

```powershell
flutter analyze
flutter test
flutter build web
```

يفحص GitHub Actions الكود والاختبارات ويبني نسخة الويب، ثم يرفق نسخة قابلة للتنزيل ولقطات للواجهة. لا ينشر الموقع ولا يرفع تطبيقاً إلى المتاجر.

## بنية المشروع

- lib/main.dart: تشغيل التطبيق، الترجمة، المظهر والتنقل المتجاوب.
- lib/src/state.dart: نماذج البيانات والحالة التجريبية.
- lib/src/components.dart: الألوان والبطاقات والمكونات المشتركة.
- lib/src/core_screens.dart: الرئيسية والاكتشاف والنتائج والحجوزات.
- lib/src/experience.dart: البانرات والقصص وخطة العناية والعائلة والمقارنة والمكافآت.
- lib/src/booking.dart: رحلة الحجز والتحقق من المدخلات.
- lib/src/account_screens.dart: العائلة والإعدادات والمشاركة والمكافآت.
- lib/src/services_screens.dart: الخدمات الإضافية ومعاينة الإدارة.
- test: اختبارات التحقق والتفاعل والعرض.

ملفات src أجزاء من مكتبة main.dart للحفاظ على مشروع بسيط بلا حزم إدارة حالة خارجية. عند مرحلة الربط ستُنقل البيانات إلى مستودعات خدمات بواجهات محددة، مع جلسات هوية موثقة وصلاحيات وملفات دائمة.

المراجع: [ترجمة تطبيقات Flutter](https://docs.flutter.dev/ui/internationalization)، [بناء نسخة الويب](https://docs.flutter.dev/deployment/web).
