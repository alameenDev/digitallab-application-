# تغطية الإصدار 0.2

هذا تسليم واجهات تفاعلية للمراجعة، وليس نظام رعاية صحية جاهزاً للإطلاق. جميع الأسماء والمبالغ والنتائج والفروع وهمية. لا توجد اتصالات شبكة من منطق التطبيق؛ قد يحمّل محرك Flutter Web خطوط العرض وملفات المحرك عند التشغيل.

| المجال | المتاح الآن | ما يتبع عند الربط |
|---|---|---|
| التصميم والتنقل | خمس تبويبات، تنقل جانبي للشاشات الكبيرة، عربي RTL وإنكليزي LTR، مظهر فاتح/داكن/النظام، تكبير الخط | هوية معتمدة، خط عربي مضمّن وتدقيق وصولية كامل |
| الدخول | نموذج هاتف عراقي وOTP تجريبي 000000، واجهة تفضيل البصمة والأجهزة | SMS، تحقق هوية موثوق، بصمة فعلية، جلسات ودخول آمن |
| العائلة | إضافة فرد وتبديل الملف، عزل نتائج وحجوزات كل فرد، حقول صحية وبطاقة طوارئ | تحقق الهوية وموافقة ربط ملفات البالغين |
| النتائج | قائمة جاهزة/قيد الإجراء، منع عرض قيم للتقرير غير الجاهز، تفاصيل القيم والمديات، مقارنة مرسومة من الأرقام المعروضة | جزئي/تمت المراجعة، نتائج حقيقية، PDF موقع، تنزيل وطباعة ومشاركة مستند |
| الحجز | تحقق الهاتف والعنوان، زيارة حضورية/منزلية/استشارة، يوم ووقت، ملاحظات محفوظة، مراجعة السعر، تطبيق DIGITAL10، موافقة | توفر حقيقي، سياسات إلغاء، إشعارات، أوامر دفع |
| إدارة الحجوزات | قائمة حسب الفرد والحالة، تعديل الموعد، إلغاء، محاكاة الاكتمال، تقييم | تأكيد مقدم الخدمة، استرداد، قيود إعادة الجدولة |
| السحب المنزلي | تسع مراحل توضيحية وزر تقدم تجريبي | تعيين فني، تتبع مباشر وإشعارات الموقع |
| الأطباء والمختبرات | بحث وفلاتر نوع/منطقة، ملفات تجريبية، فروع وباقات، مفضلة وسجل مشاهدة | تحقق التراخيص والمؤهلات، أوقات وتقييمات وعناوين موثقة |
| الاستشارات | غرفة محاكاة صوت/فيديو ورسائل محلية دون فتح الكاميرا أو الميكروفون | اتصال، دفع، وصفات وتوثيق الاستشارة |
| المساعد | أسئلة محلية ورد توضيحي ثابت مع إظهار أنه ليس AI متصلاً | موافقة فعالة، نموذج معتمد، ضوابط التحليل، تصعيد للطبيب |
| المشاركة | فرد ونطاق ومستلم ومدة وإلغاء، الحالة تحسب الانتهاء عند إعادة البناء | روابط وتوكنات، تحقق المستلم، إنفاذ الصلاحيات وسجل تدقيق |
| المستندات | إضافة وحذف عنوان مستند | اختيار ملفات، رفع آمن، تشفير وتخزين دائم |
| التذكيرات | عنوان وموعد وحالة إنجاز في الجلسة | إشعارات مجدولة ومزامنة |
| الولاء | أرصدة تجريبية، عرض المستويات، استبدال 500 نقطة وسجل | قواعد الكسب، المعلّق، الانتهاء، قسائم حقيقية |
| المحفظة والمدفوعات | رصيد ثابت موسوم كتوضيح وملخصات الحجوزات غير المدفوعة | مزود دفع، إيصالات، استرداد وسجل مالي |
| الإحالات والعروض | كوبون الباقات محلي، نسخ رمز إحالة تجريبي | روابط دعوات، QR، مكافحة إساءة الاستخدام، احتساب الإحالات |
| الإشعارات | ثلاث رسائل تجريبية وروابط للشاشات وحالة القراءة | push، صلاحيات الجهاز، تفضيلات مُنفذة على الخادم |
| الصيدلية | طلب محلي وعرض الاستلام/التوصيل، لا بيع أدوية | وصفة متحققة، مخزون وتوفر وأسعار وتوصيل |
| التأمين | معاينة وثيقة غير مرتبطة وطلبات ربط محلية | أهلية وتغطية وشركات ومطالبات فعلية |
| الدعم | FAQ وتذاكر محلية وتقييم نجوم وNPS | دعم فعلي، هاتف وواتساب ودورة تذاكر |
| بطاقة المريض | بطاقة عرض، أيقونة QR موسومة كعنصر غير قابل للمسح، رقم دور محاكى | رمز موقع، تحقق دخول وطابور مباشر |
| الخريطة | قائمة فروع ومساحة مخصصة للخريطة | مزود خرائط، إحداثيات وملاحة وصلاحيات الموقع |
| الخصوصية | تفضيلات محلية ومعاينة طلب تصدير/حذف | سياسة معتمدة، إنفاذ الموافقات والحذف والتصدير |
| الإدارة | استوديو معاينة وقوائم ومسودات وعدّادات جلسة | بوابة منفصلة مؤمنة، CRUD كامل، أدوار، حملات وإشعارات، فنيون، تقارير وإيرادات واشتراكات ورعاة وسجل تدقيق |

حالة البيانات محلية ومؤقتة. أسماء المستندات والتذاكر والمكافآت تابعة لحساب العرض؛ البيانات الصحية والنتائج والحجوزات وأذونات التقارير تتبع الفرد المحدد. لا تدخل بيانات مريض حقيقي في هذا الإصدار.

بناء Android وiOS وتوقيعهما واختبار الأجهزة الفعلية غير مشمول في فحص الويب. ملفات المنصتين تُولد بالأمر الموجود في README.
